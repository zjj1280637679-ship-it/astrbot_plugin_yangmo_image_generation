# AI 图片生成与原图交付

让你的 AstrBot AI 独立完成图片生成、参考图编辑、合成、预览和原图发送。插件自带方舟异步客户端、一次性任务状态、创作知识、`genimg:` 存储和原图交付通道，不要求安装图片定位器、聊天记录搜索器或其他羊魔插件。

交流与反馈：**QQ 群 916646029**

## 你会得到什么

- 默认按高到低的固定模型顺序尝试；只有额度或限流类错误才降级，不随机轮换。
- 生成前先向你预告，随后才调用真实图片 API。
- 生成结果先作为内部预览返回给 AI；这不等于已经发送到 QQ。
- AI 确认后再把生成物作为原文件发送，避免 QQ 聊天图片压缩。
- 支持当前消息图片或本插件历史生成物作为参考图。
- 图片数量直接服从你的任务要求；插件不接管服务商额度或计费规则，也不会为了补足张数循环发起额外请求。

## 完整生命周期

```text
A ::= 非空预告
K ::= 0..3 个作品技能 ID
t ::= 当前事件的一次性任务句柄
p ::= 完整图片指令
r ::= "current" | "genimg:" + 16位十六进制
R ::= [] | [r1,...,rk]
G ::= [genimg:...,...]
n ::= 1..15（方舟接口参数边界，不是插件配额）

prepare_image_generation(A,K) -> t
generate_image(t,p,R,n,a) -> G + preview
send_generated_images(G) -> 原文件真实发送
```

顺序固定为：

```text
接受任务
  -> prepare（不发消息、不调用 API）
  -> generate 消费 t
  -> 发送 A
  -> 调用图片 API
  -> 保存原图并返回 G/preview
  -> AI 继续回应
  -> 需要交付时 send(G)
```

`t` 只属于当前事件且只能使用一次；生成失败后要重新准备。`preview` 只给 AI 查看，`send` 才会把原图交付到当前聊天。

## 安装

1. 在 AstrBot 插件管理中使用仓库 URL 安装，或上传精简 ZIP。
2. 确认 AstrBot 版本满足 `>=4.26.1`（不设版本上限）。
3. 在插件配置中填写火山方舟 API Key；密钥默认值始终为空。
4. 按你的服务开通情况检查模型名与接口地址，然后保存并重载插件。
5. `aiocqhttp` 支持原文件交付；WebChat 可用于预览和工具回归。

## 配置

| 配置项 | 默认值 | 作用 |
| --- | --- | --- |
| `ark_api_key` | 空 | 方舟普通图片 API 密钥 |
| `ark_base_url` | 方舟北京普通接口 | 普通计费/额度接口地址 |
| `image_models` | 5 Pro → 5 → 4.5 | 普通接口的固定模型优先级 |
| `image_model` | 5 Pro | 模型列表为空时的兜底模型 |
| `image_size` | `5461x3072` | 无法识别画幅时的质量预算 |
| `ark_plan_fallback` | `true` | 普通接口均为额度/限流错误后再尝试套餐接口 |
| `ark_plan_base_url` | 方舟套餐接口 | 套餐接口地址 |
| `ark_plan_api_key` | 空 | 套餐密钥；留空复用普通密钥 |
| `ark_plan_image_model` | Seedream 5 Lite | 套餐兜底模型 |
| `ffmpeg_bin` | `ffmpeg` | 制作内部预览；失败不影响原图 |
| `generated_ttl_days` | `30` | 本插件生成物保留天数 |
| `max_store_bytes` | `2147483648` | 本插件生成物总空间上限 |

## 模型、尺寸与计费边界

- 每个候选模型最多调用一次。组图模型少返回时保留已成功结果，不循环补画；单图模型不会被插件循环调用来凑多张。
- 只有候选模型零结果且返回额度/限流类错误时，才尝试下一候选；一旦得到任何成功图片便停止降级。
- 成功与失败回执都给出插件实际发起的 `api_calls`，便于核对调用副作用。
- 普通模型降级和套餐兜底只在额度、限流等可恢复错误后发生；提示词错误、参数错误等不会偷偷换模型。
- `aspect` 先映射到高质量尺寸，再在目标模型明确的像素上下界内做等比例适配；插件不会为了假想的 Token 节省主动降低像素。
- 尺寸必须满足目标模型的总像素和 `1:16..16:1` 比例边界；本地拒绝必然失败的参数不会产生 API 调用。
- 服务商如何计费、给多少额度、何时限流，由 API 后台决定；本插件不建立第二套次数或配额判断。
- 调用生成工具会产生真实外部 API 请求。测试发布面时不应自动进行付费生成。

## 参考图与独立性

- `current` 只代表当前用户消息里的图片。
- `genimg:` 只代表本插件在当前会话作用域保存的生成物。
- 参考图按内容去重，最多 14 张、单张最多 30 MiB；宽和高都必须大于 14 像素、比例须在 `1:16..16:1` 内、总像素不超过 3600 万。5 Pro 候选最多接收 10 张，超过时会选择后续兼容模型而不是先发一个必失败请求。
- 其他插件的提取码、QQ `file_id` 或任意临时 ID 不属于本插件引用域。
- 每个插件拥有独立客户端、状态、存储和句柄；联合安装也不会共享内部基础设施。

## 隐私与失败语义

- API Key 只从 AstrBot 插件配置读取，不写入日志、工具回执、README 或发布包。
- 参考图会按方舟接口要求提交给你配置的服务商；请遵守服务商隐私与内容规则。
- 原图保存在 AstrBot 插件数据目录，更新插件不会覆盖；过期和空间清理由本插件负责。
- 清理在新一轮生成前执行且失败不阻断生成，不会在预览制作前删除刚生成的唯一原图。
- 内部预览失败时仍保留原图和 `genimg:`；原图发送失败会返回结构化失败，不冒充已交付。
- 本插件不自行修改 AstrBot 人格、主对话历史或其他插件配置。
