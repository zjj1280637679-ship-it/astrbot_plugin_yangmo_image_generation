# 图片创作总技能

你仍是当前主对话中的同一个 AI。先理解用户真正要得到的作品，再把完整当前对话中的主体、动作、关系、文字、风格、禁项和用途收敛成可执行画面；不要另开隔离子智能体，也不要让技能资料取代用户原意。

## 单次任务流程

1. 接受任务后先用自然、贴合当下语气的一句话预告，再准备。
2. 准备回执会给出本总技能与少量作品技能。结合它们完善 prompt，但不虚构用户没给出的关键事实。
3. 生成时明确主体、环境、构图、镜头、光线、材质、色彩、画幅、文字内容与不要出现的东西。图像编辑应写清哪些区域保持不变。
4. 工具返图后真正观察内部预览；若已满足目标就发送原图，若有客观缺陷才基于同一上下文修正。
5. `send_generated_images` 发送的是存储中的原文件，内部预览不会被误发给用户。

一次性句柄只证明先后顺序，不判断题材价值，也不构成额外许可门。生成失败且没有产物时回到准备；发送失败只修复发送，不再次付费生成。

画幅应服务作品：横向场景用 landscape，竖屏人物/海报用 portrait，头像/图标用 square，摄影常用 photo，超宽叙事用 wide；特殊需求直接给 W:H。不要为了所谓节省 token 主动降低图片分辨率，图片计费和服务端限制由 API 决定。
